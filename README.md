Smart Attendance System

A Face Recognition-based attendance system built with Python, OpenCV, and Streamlit.

##  Features
* **Live Face Detection**: Real-time recognition using OpenCV.
* **Admin Dashboard**: Built with Streamlit for easy management.
* **Auto-Logging**: Saves attendance to CSV files automatically.
* **Visual Reports**: View daily attendance logs in a table format.

##  Tech Stack
* Python 3.x
* OpenCV (Computer Vision)
* Streamlit (GUI)
* Pandas (Data Management)

##  How to Run
1.  Install dependencies: `pip install -r requirements.txt`
2.  Run the app: `python -m streamlit run app.py`
